## What it does

<CardGrid>
  <Card title="Drop-in for provider SDKs" icon="rocket">
    Resend and Brevo SDKs or any SMTP client send to Mailsink with a base URL or host
    change.
  </Card>
  <Card title="Ephemeral workspaces for CI" icon="puzzle">
    One isolated, self-expiring workspace per test worker, reset between tests.
  </Card>
  <Card title="Failure simulation" icon="warning">
    Force bounces, latency, rate limits and chaos errors through temporary overrides.
  </Card>
  <Card title="Assert over HTTP or MCP" icon="approve-check">
    Wait for an email, extract links and codes, check signed webhooks, from tests or AI
    agents.
  </Card>
</CardGrid>
